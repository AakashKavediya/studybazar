01 — Overview

One marketplace.
Built for students, by a student.

StudyMart replaces scattered WhatsApp groups and generic marketplaces with one place to trade academic essentials. Every session runs through short-lived access tokens paired with rotating, TTL-indexed refresh tokens — so accounts stay secure without students noticing the machinery.

⚡ Next.js 🐍 FastAPI 🍃 MongoDB 🔑 JWT (Access + Refresh) ☁️ Cloudinary 🔴 Redux Toolkit

04 — Token Lifecycle

Access tokens expire fast.
Refresh tokens rotate quietly.

Every refresh call issues a brand-new refresh token and invalidates the old one — the TTL index clears expired entries from MongoDB automatically.

07 — Environment Variables

Copy, fill in,

Copy .env.example to .env and fill in your own values. Never commit .env.

JWT_SECRET_KEY=your-secret-key-here

CLOUDINARY_API_KEY=your_api_key

08 — Local Setup

Running in
under five minutes.

1
Clone the repository
BASH
git clone https://github.com/your-org/studymart.git
cd studymart
2
Backend (FastAPI)
BASH
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# API docs → http://localhost:8000/docs
3
Frontend (Next.js)
BASH
cd frontend
npm install
cp ../.env.example .env.local
npm run dev
# App → http://localhost:3000
09 — API Reference

REST, versioned,
self-documented.

All endpoints are prefixed /api/v1/. Interactive docs are auto-generated at /docs.

🔐 Auth
MethodEndpointDescription
POST/auth/signupCreate an account
POST/auth/loginLogin, returns access + refresh tokens
POST/auth/refreshRotate access + refresh tokens
POST/auth/logoutInvalidate the current refresh token
🏪 Products
MethodEndpointDescription
GET/productsBrowse listings, with filters
POST/productsCreate a new listing
GET/products/{id}Fetch a single listing
PATCH/products/{id}Update a listing (owner only)
DELETE/products/{id}Remove a listing (owner only)

11 — Security

Rotation over reuse.

🔑

Access + Refresh Split

Short-lived access tokens (15 min) paired with longer-lived refresh tokens (7 days).

🔄

Refresh Rotation

Every refresh call issues a new token pair and invalidates the previous refresh token.

🍃

TTL-Indexed Storage

MongoDB automatically removes expired refresh tokens — no cleanup job required.

🛡️

Pydantic Validation

Every request body is validated before it touches the database.
